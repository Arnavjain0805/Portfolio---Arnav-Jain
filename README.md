# Arnav Jain - Personal Portfolio

Welcome to the repository for my personal portfolio website! I am a B.Tech Computer Science student at NMIMS, and this site is designed to showcase my skills, projects, and journey in the tech world. 

I intentionally built this project from scratch using vanilla web technologies to demonstrate a strong understanding of core frontend fundamentals without relying on heavy frameworks.

## ✨ Features
*   **Storytelling UI:** A sequential layout that guides the user through my background, skills, and work.
*   **Parallax Scrolling:** Custom background effects using Vanilla JS and CSS for a dynamic, deep visual experience.
*   **Zero Dependencies:** Built entirely without external frameworks or libraries for maximum speed and lightweight performance.
*   **Fully Responsive:** Fluid design that adapts seamlessly to desktop, tablet, and mobile screens.
*   **Interactive Elements:** Hover states, smooth transitions, and dynamic project cards.

## 🛠️ Tech Stack
*   **HTML5:** Semantic structuring.
*   **CSS3:** Custom styling, flexbox/grid layouts, animations, and media queries.
*   **Vanilla JavaScript:** Scroll event listeners for parallax effects and dynamic interactions.

## 📂 Featured Projects
This portfolio highlights several of my key technical projects, including:
*   **GenZ Lang:** A custom programming language featuring a complete compiler pipeline built with Flex, Bison, and C.
*   **Surface Defect Detection:** An automated visual inspection tool using Python, OpenCV, and Machine Learning.
*   **Collaborative Study App:** A study platform built for sharing notes, quizzes, and flashcards.
*   **HelixAero Ops Suite:** An application for managing aircraft records, maintenance, and inventory.

## 🚀 How to Run Locally
Since this project uses pure HTML, CSS, and JS, there is no need to install dependencies or run a build server.
1. Clone the repository: `git clone https://github.com/Arnavjain0805/portfolio.git`
2. Navigate to the project folder.
3. Simply open `index.html` in any modern web browser!
